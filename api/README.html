AI Reader API

AI Reader API is a public Ongsoo Labs service for converting web pages into clean Markdown, text, or structured JSON with usage, quality, and execution metadata for AI workflows.

Public access is available through RapidAPI. Direct calls to https://api.ongsoolabs.com are reserved for platform and partner integrations unless separately arranged.

Overview

Web page -> Content extraction -> Boilerplate removal -> Markdown/text/JSON output -> Usage, quality, and execution metadata

Key Features

  • AI-ready content: Converts the main page content into Markdown, text, or structured JSON suitable for AI prompts and indexing.
  • Content and title extraction: Filters common navigation, layout, and advertising noise.
  • Contracted metadata: Returns usage, quality, and execution metadata for cost, confidence, and runtime visibility.
  • Standard errors: Returns stable error codes for invalid, unsafe, blocked, or failed reads.
  • Output options: Lets callers choose whether to include optional links, images, tables, and code blocks.
  • Reader modes: Supports content-oriented modes such as article, documentation, product, forum, and generic.

Authentication

Use the X-RapidAPI-Key and X-RapidAPI-Host values shown in your RapidAPI dashboard.

API Endpoints

Method Path Description
GET /v1/reader Text conversion and analysis using URL parameters
POST /v1/reader Advanced options through a JSON body
POST /v1/reader/chunk Split text into chunks for downstream AI processing

POST /v1/reader Request Example

POST /v1/reader
Content-Type: application/json
X-RapidAPI-Key: <your-rapidapi-key>
X-RapidAPI-Host: <your-rapidapi-host>

{
  "url": "https://example.com",
  "output_format": "markdown",
  "mode": "article",
  "tokenizer": "openai",
  "output": {
    "content": true,
    "metadata": true,
    "tables": true,
    "codeBlocks": true,
    "images": false,
    "links": false
  }
}

Local Development

Source development requires the .NET 10 SDK. Docker is used for containerized local and deployment environments.

For local reader development, run TextProcessor and Scraper together:

dotnet run --project C:\Project\OngsooLabs.Api\src\Services\TextProcessor\OngsooLabs.TextProcessor.WebApi\OngsooLabs.TextProcessor.WebApi.csproj --launch-profile http
dotnet run --project C:\Project\OngsooLabs.Api\src\Services\Scraper\OngsooLabs.Scraper.WebApi\OngsooLabs.Scraper.WebApi.csproj --launch-profile http

In Development, Scraper uses TEXT_PROCESSOR_URL = http://localhost:5176 from appsettings.Development.json.
