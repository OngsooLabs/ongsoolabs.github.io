Reader Benchmark Datasets

This directory stores benchmark inputs for /v1/reader regression checks.

Files

  • reader-seed-dataset.json: 30 URL seed dataset for Phase 1.5 Milestone 3.
  • reader-lock-dataset.json: 100 URL lock dataset for release-gate regression checks.
  • reader-lock-candidate-batch-001.json: 18 verified URLs for the first lock expansion batch.
  • reader-lock-candidate-batch-002.json: 19 verified URLs for the second lock expansion batch.
  • reader-lock-candidate-batch-003.json: 17 verified URLs for the third lock expansion batch.
  • reader-lock-candidate-batch-004.json: 16 verified URLs for the final lock expansion batch.
  • reader-seed-dataset.schema.json: JSON Schema for benchmark dataset files.
  • reader-lock-dataset-plan.md: Category mix, promotion workflow, and exit criteria for the 100 URL lock dataset.

Dataset Intent

The seed dataset is not the final lock dataset. It exists to make the first Markdown regression runner reviewable before expanding coverage to 100 URLs.

The lock dataset should be created only after candidate batches pass locally. Use reader-lock-dataset-plan.md to keep category coverage balanced while expanding from 30 to 100 URLs.

Each item captures:

  • A public HTTPS URL.
  • The intended /v1/reader request shape.
  • Stable content expectations through mustContain.
  • Failure and boilerplate guards through mustNotContain.
  • Risk tags that explain why the page belongs in the benchmark.

Runner Policy

The first automated runner should treat this file as data, not as test code. It should call /v1/reader, extract the returned content, and verify:

  • Response status is success.
  • Markdown or text content length is at least minCharacters.
  • Every mustContain value is present.
  • No mustNotContain value is present.
  • Dataset item failures report id, url, and the failed expectation.

The runner must not log request bodies, response bodies, raw HTML, cookies, custom headers, proxy configuration, or extracted content.

Local Runner

Run the scraper API locally, then execute:

.\scripts\run-reader-benchmark.ps1 -BaseUrl http://localhost:5243

If local PowerShell execution policy blocks direct script execution, use:

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-reader-benchmark.ps1 -BaseUrl http://localhost:5243

Useful options:

.\scripts\run-reader-benchmark.ps1 -BaseUrl http://localhost:5243 -IncludeId seed-001,seed-002
.\scripts\run-reader-benchmark.ps1 -BaseUrl http://localhost:5243 -StopOnFirstFailure
.\scripts\run-reader-benchmark.ps1 -BaseUrl http://localhost:5243 -RapidApiProxySecret $env:RAPIDAPI_PROXY_SECRET
.\scripts\run-reader-benchmark.ps1 -DryRun

The script exits with code 0 when all selected items pass and 1 when any item fails.
