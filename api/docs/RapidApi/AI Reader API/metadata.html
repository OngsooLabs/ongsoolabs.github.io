AI Reader API RapidAPI Metadata

Short Description

Convert public webpages into clean, LLM-ready Markdown, text, or structured JSON for RAG, AI agents, and knowledge-base ingestion.

Long Description

AI Reader API turns messy public webpages into clean content your AI applications can use immediately. Most integrations start with the extracted content field, then use optional usage, quality, execution, and chunking metadata when they need cost visibility, debugging, or RAG pipeline tuning.

Use it to power AI agents, RAG pipelines, web-content ingestion jobs, automated summarizers, documentation indexers, and knowledge-base builders without building your own scraper, boilerplate cleaner, response contract, tokenizer estimator, and chunking layer.

Key Capabilities

  • Webpage to LLM-Ready Content: Convert public URLs into clean Markdown, plain text, or structured JSON.
  • Boilerplate Removal: Filter common navigation, ads, scripts, footers, sidebars, and repeated layout text.
  • RAG-Friendly Chunking: Split extracted page content or raw text into overlapping chunks for embedding workflows.
  • Simple Response Path: Read extracted Markdown, text, or structured article content first.
  • Optional Usage Metadata: Check character count, token estimate, chunk count, and response credit metadata when needed.
  • Optional Quality Metadata: Inspect v0 quality signals, confidence, and warnings for debugging or tuning.
  • Optional Execution Metadata: Check execution profile, browser usage, cache status, retry count, and duration.
  • Metadata Extraction: Return available title, author, published date, language, excerpt, lead image, word count, and reading time.
  • Standard Errors: Return stable error codes with retryability, recommended profile, and user-actionable guidance.
  • Flexible Extraction Modes: Tune output for article, documentation, product, forum, or generic pages.
  • Hybrid Retrieval: Start with fast static retrieval and use dynamic rendering when needed.
  • RapidAPI-Managed Quota: RapidAPI controls public request quota, overage pricing, bandwidth platform fees, and subscription state.

Public Endpoints

  • GET /v1/reader: Convert a webpage using URL query parameters.
  • POST /v1/reader: Convert a webpage using JSON options.
  • POST /v1/reader/chunk: Split raw text into overlapping chunks.

The public API is designed for safe processing of public webpages and focuses on URL-based extraction, output formatting, token estimation, and chunking controls.

RapidAPI Quota and Policy Baseline

Successful reader calls return usage.credits = 1 and failed reader calls return usage.credits = 0 as response metadata. Public request quota, enabled plans, overage pricing, bandwidth platform fees, and currency pricing are controlled by the active RapidAPI plan.

Users are responsible for complying with applicable laws and target-site terms. The API must not be used to bypass paywalls, authentication, authorization, bot protections, or technical access controls.
