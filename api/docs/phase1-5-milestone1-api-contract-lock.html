Phase 1.5 Milestone 1: API Contract Lock

Milestone 1 locks the public /v1/reader response contract for AI Reader API v1. This milestone is an intentional breaking change from the earlier success/content/metadata shape.

Status

Implemented and locally verified.

  • GET /v1/reader and POST /v1/reader now use the standard success and error envelopes.
  • schemaVersion, apiVersion, and quality.version are centralized in domain constants.
  • Reader failures now return structured error responses with stable error codes.
  • /v1/reader/chunk remains on its legacy response shape and is planned for later alignment.

Success Response Shape

All successful reader responses include:

  • id
  • schemaVersion
  • apiVersion
  • url
  • finalUrl
  • status
  • contentType
  • title
  • description
  • language
  • content
  • metadata
  • usage
  • quality
  • execution
  • chunks, when chunking is enabled

Content Contract

content is a discriminated object.

  • markdown and text outputs use content.value.
  • json output uses content.article.
  • value and article are mutually exclusive.
{
  "content": {
    "format": "json",
    "article": {
      "title": "Example Domain",
      "body": "Clean body text..."
    }
  }
}

Error Response Shape

All reader failures return:

  • id
  • schemaVersion
  • apiVersion
  • url
  • status = failed
  • error
  • usage
  • execution

Example:

{
  "id": "read_abc123",
  "schemaVersion": "2026-07-01",
  "apiVersion": "v1",
  "url": "http://127.0.0.1",
  "status": "failed",
  "error": {
    "code": "UNSAFE_URL",
    "message": "The provided URL is unsafe or targets internal network assets.",
    "retryable": false,
    "recommendedProfile": "",
    "userActionable": true
  },
  "usage": {
    "characters": 0,
    "tokens": 0,
    "chunks": 0,
    "credits": 0
  },
  "execution": {
    "profile": "fast",
    "usedBrowser": false,
    "cache": "miss",
    "retryCount": 0,
    "durationMs": 9
  }
}

Error Codes

Code HTTP status Retryable
INVALID_URL 400 false
INVALID_REQUEST 400 false
UNSAFE_URL 403 false
RENDER_REQUIRED 422 true
BLOCKED_BY_SITE 422 false
FETCH_FAILED 502 true
INTERNAL_ERROR 500 true

Execution Metadata

execution.profile describes the execution strategy, not the content mode.

  • fast: static HTTP retrieval path.
  • standard: browser rendering or forced dynamic path.

contentType continues to describe the extraction/content mode, such as article, documentation, product, forum, or generic.

Local Development Notes

For local development, run TextProcessor and Scraper together if accurate token counts are required.

dotnet run --project C:\Project\OngsooLabs.Api\src\Services\TextProcessor\OngsooLabs.TextProcessor.WebApi\OngsooLabs.TextProcessor.WebApi.csproj --launch-profile http

dotnet run --project C:\Project\OngsooLabs.Api\src\Services\Scraper\OngsooLabs.Scraper.WebApi\OngsooLabs.Scraper.WebApi.csproj --launch-profile http

In Development, Scraper uses TEXT_PROCESSOR_URL = http://localhost:5176 from appsettings.Development.json.

Development also skips AWS Secrets Manager loading by default. Set ONGSOOLABS_LOAD_AWS_SECRETS=true to opt in.
