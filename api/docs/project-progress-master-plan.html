이 문서는 AI Reader API의 제품 방향, 구현 완료된 마일스톤, 남은 Phase 1.5 작업, Phase 2 진입 조건을 관리하는 기준 문서입니다.

현재 구현 요약

Phase 1.5 Milestone 1, API Contract Lock은 GET /v1/reader와 POST /v1/reader에 대해 구현 완료되었습니다.

구현 완료 항목:

  • 버전이 포함된 성공 응답 envelope.
  • 버전이 포함된 에러 응답 envelope.
  • schemaVersion = 2026-07-01, apiVersion = v1, quality.version = qv0.
  • Reader 계약 버전 상수 중앙화.
  • value와 article이 상호 배타적인 ReaderContent wrapper.
  • 강타입 QualitySignals.
  • 표준 reader error code.
  • 실패 응답에서 characters, tokens, chunks, credits를 모두 0으로 반환하는 fast-fail usage 처리.
  • 응답 레벨의 usage, quality, execution metadata.
  • execution.profile은 실행 전략으로 분리: fast 또는 standard.
  • contentType은 추출 모드로 분리: article, documentation, product, forum, generic.
  • 캐시 응답 재사용 시 캐시 원본 객체를 변이하지 않도록 수정.
  • RapidAPI 문서와 DocFX 문서 갱신.
  • tests/Services/Scraper/OngsooLabs.Scraper.WebApi.Tests에 계약 테스트 추가.
  • 로컬 개발 환경에서 Scraper가 TextProcessor를 http://localhost:5176으로 호출하도록 기본값 정리.

알려진 후속 작업:

  • POST /v1/reader/chunk는 아직 기존 응답/에러 형식을 유지합니다.
  • Browser fallback 차등 credit 정책은 아직 구현하지 않았습니다.
  • Benchmark dataset과 Markdown regression test는 아직 구현하지 않았습니다.
  • 외부 telemetry sink/dashboard는 아직 구현하지 않았습니다.

제품 방향

AI Reader API는 OngsooLabs API 플랫폼의 첫 번째 제품입니다. 역할은 공개 웹 페이지를 LLM, RAG, 검색, 요약, 지식 수집 워크플로에 바로 사용할 수 있는 AI-ready content로 변환하는 것입니다.

제품이 우선해야 할 기준:

  • 안정적인 공개 API 계약.
  • 설명 가능한 실패 응답.
  • 비용과 실행 과정의 가시성.
  • 반복 가능한 품질 검증.
  • 사용자가 요청한 공개 URL에 대한 안전한 처리.

장기 확장 후보:

  • AI Utilities API.
  • Sitemap Watchdog API.
  • AI Extraction API.
  • Batch, crawl, async job API.
  • Enterprise workspace와 scheduled ingestion 기능.

  • 공개 문서는 /v1/reader 기준으로 통일합니다.

Reader 성공 응답

GET /v1/reader와 POST /v1/reader는 표준 성공 envelope를 반환합니다.

{
  "id": "read_xxx",
  "schemaVersion": "2026-07-01",
  "apiVersion": "v1",
  "url": "https://example.com/article",
  "finalUrl": "https://example.com/article",
  "status": "success",
  "contentType": "article",
  "title": "Example Article",
  "description": "Example description",
  "language": "en",
  "content": {
    "format": "markdown",
    "value": "# Example Article\n\n..."
  },
  "metadata": {},
  "usage": {
    "characters": 16842,
    "tokens": 4210,
    "chunks": 5,
    "credits": 1
  },
  "quality": {
    "version": "qv0",
    "score": null,
    "grade": null,
    "confidence": "medium",
    "signals": {
      "contentLength": 16842,
      "markdownLength": 16842,
      "headingCount": 14,
      "linkDensity": 0.08,
      "boilerplateRatio": null,
      "duplicateParagraphRatio": 0.03,
      "codeBlockCount": 5,
      "tableCount": 2,
      "imageCount": 0,
      "languageDetected": "en",
      "htmlToMarkdownRatio": 0.42,
      "mainContentExtractionRatio": null
    },
    "warnings": []
  },
  "execution": {
    "profile": "fast",
    "usedBrowser": false,
    "cache": "miss",
    "retryCount": 0,
    "durationMs": 842
  },
  "chunks": []
}

Content 규칙:

  • markdown과 text는 content.value를 사용합니다.
  • json은 content.article을 사용합니다.
  • content.value와 content.article은 동시에 채워질 수 없습니다.

Reader 실패 응답

Reader 실패는 표준 error envelope를 반환합니다.

{
  "id": "read_xxx",
  "schemaVersion": "2026-07-01",
  "apiVersion": "v1",
  "url": "http://127.0.0.1",
  "status": "failed",
  "error": {
    "code": "UNSAFE_URL",
    "message": "The provided URL is unsafe or targets internal network assets.",
    "retryable": false,
    "recommendedProfile": "",
    "userActionable": true
  },
  "usage": {
    "characters": 0,
    "tokens": 0,
    "chunks": 0,
    "credits": 0
  },
  "execution": {
    "profile": "fast",
    "usedBrowser": false,
    "cache": "miss",
    "retryCount": 0,
    "durationMs": 9
  }
}

구현된 error code:

Code HTTP status Retryable Credit policy
INVALID_URL 400 false 0
INVALID_REQUEST 400 false 0
UNSAFE_URL 403 false 0
RENDER_REQUIRED 422 true 0
BLOCKED_BY_SITE 422 false 0
FETCH_FAILED 502 true 0
INTERNAL_ERROR 500 true 0

추후 확장할 error code:

  • TIMEOUT
  • CONTENT_TOO_SHORT
  • UNSUPPORTED_CONTENT_TYPE
  • RATE_LIMITED
  • CACHE_ERROR
