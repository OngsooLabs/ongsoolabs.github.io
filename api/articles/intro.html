Introduction to OngsooLabs API

Welcome to the official documentation for public Ongsoo Labs API services.

OngsooLabs API focuses on practical data preparation tools for AI applications. The first public service, AI Reader API, helps developers turn web pages into clean Markdown and metadata that can be used in LLM, RAG, search, and summarization workflows.

What the Platform Provides

  • Content extraction: Identify the main readable content from a target web page.
  • Markdown output: Return a compact format that is easier to pass into AI pipelines.
  • Analysis metadata: Include useful signals such as title, language, word count, token estimate, and reading time where available.
  • Output controls: Let callers choose whether optional items such as links, images, tables, or code blocks should be included.

Public Access

Public API access is provided through RapidAPI. Use the API key, host, quota, and pricing information shown in your RapidAPI dashboard.

Direct requests to https://api.ongsoolabs.com are reserved for platform and partner integrations unless separately arranged.

Available APIs

  • AI Reader API: Fetches a web page, removes common boilerplate, converts the main content to Markdown, and returns analysis metadata for AI workflows.

Usage Responsibility

Callers are responsible for complying with the terms of service, robots policies, copyright rules, and applicable laws for each target website they process.
