AI Reader API

AI Reader API converts web pages into clean Markdown and metadata for LLM, RAG, search, and summarization workflows.

Available on RapidAPI

How It Works

Web page -> Content extraction -> Boilerplate removal -> Markdown conversion -> Metadata analysis -> AI-ready output

Key Features

  • Markdown conversion: Converts the main page content into Markdown suitable for AI prompts and indexing.
  • Content and title extraction: Filters common navigation, layout, and advertising noise.
  • Language and metric analysis: Returns metadata such as language, word count, token estimate, and reading time where available.
  • Output options: Lets callers choose whether to include optional links, images, tables, and code blocks.
  • Reader modes: Supports content-oriented modes such as article, documentation, product, forum, and generic.

Authentication

Public access is handled by RapidAPI. Use the X-RapidAPI-Key and X-RapidAPI-Host values shown in your RapidAPI dashboard.

Direct calls to https://api.ongsoolabs.com are reserved for platform and partner integrations unless separately arranged.

API Endpoints

Method Path Description
GET /v1/reader Text conversion and analysis using URL parameters
POST /v1/reader Advanced options through a JSON body
POST /v1/reader/chunk Split text into chunks for downstream AI processing

POST /v1/reader Request Example

POST /v1/reader
Content-Type: application/json
X-RapidAPI-Key: <your-rapidapi-key>
X-RapidAPI-Host: <your-rapidapi-host>

{
  "url": "https://example.com",
  "mode": "article",
  "tokenizer": "openai",
  "output": {
    "content": true,
    "metadata": true,
    "tables": true,
    "codeBlocks": true,
    "images": false,
    "links": false
  }
}

Recommended Options

  • Use mode to describe the target page type. Start with article for editorial pages and documentation for developer docs.
  • Set images and links to false when you need smaller output for token-sensitive workflows.
  • Enable tables and codeBlocks when preserving technical content matters.
Note

This service processes pages requested by the caller. Callers are responsible for complying with the terms of service, robots policies, copyright rules, and applicable laws of each target website.
