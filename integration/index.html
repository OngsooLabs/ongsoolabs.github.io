Ongsoo Labs Integration Framework Documentation

Ongsoo Labs' official technical documentation for the Unity asset integration framework. This website is powered by DocFX and provides integration guides, package manuals, and generated API references for the OSL Unity asset ecosystem.

Asset Ecosystem

The Ongsoo Labs integration framework is designed so each module can work independently while still sharing common runtime, configuration, and integration patterns through OSL.Core. Browse the asset guides below by category.

  • Deterministic: Deterministic RNG, weighted draws, shuffling, and replay-friendly random state management
  • EasyPatcher: Runtime patch distribution, manifest generation, download verification, and custom loader integration
  • SocialLogin: Multi-platform authentication adapters for Google, Apple, Facebook, Steam, Discord, and related backend verification flows
  • IapClient: In-app purchase client workflow with backend receipt verification and duplicate reward protection
  • SecureSave: Server-authoritative Cloud Code and Cloud Save workflow for validated player data writes

System Requirements

The shared baseline for most OSL packages is:

  • Unity 2021.3 LTS or later
  • .NET Standard 2.1 compatible project settings
  • Assembly Definition (.asmdef) based project structure recommended

Some modules require newer Unity or Unity Gaming Services packages. Always check the Requirements section in each module guide before importing a package into production projects.
