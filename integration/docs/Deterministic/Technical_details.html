Technical Details

  • Algorithm: Uses the PCG-XSH-RR (Permuted Congruential Generator) algorithm for highly statistically uniform, fast, and predictable outputs.
  • Memory Management: Zero memory allocations during runtime generation (NextInt, NextFloat, Shuffle, RollMany).
  • State Snapshotting: PRNG state can be captured and restored instantly using 16-byte Span<byte> buffers without heap allocation, perfect for rollback netcode or save files.
  • Gacha Configuration: Gacha tables can be authored in code, via JSON, or as ScriptableObjects. Supports cumulative weight binary search for ultra-fast rolls.
  • Pity System: Includes SimpleHardPity and the IPitySystem interface to guarantee rare drops after a specific number of consecutive misses.
  • Sub-RNG Streams: Supports independent stream generation (stream id). You can derive isolated RNGs (Combat, Loot, AI) from a single master seed without cross-interference.
  • Sample Included: A split-screen OnGUI Lockstep Demo is included to prove identical frame-by-frame state hashing without desynchronization.
