Description

OSL Deterministic Core is a pure C# randomness suite built for Unity developers who need strict consistency across supported and tested platforms. If you are building lockstep multiplayer, replay systems, or strict procedural generation, non-deterministic random flows and floating-point-heavy probability logic can cause synchronization issues. This asset provides an integer-first, reproducible randomness foundation designed to reduce those risks.

Highlights

  • Deterministic by construction: Same seed produces the same sequence across supported Unity versions and tested target platforms.
  • Allocation-conscious hot paths: RNG advance, dice rolls, gacha draws, and array shuffling are designed to avoid runtime garbage allocations in core paths. State save/load utilizes Span<byte>.
  • Zero third-party dependencies: Built on pure .NET Standard 2.1. No native plugins or external runtime dependencies.
  • Integer-first probability: RollPermille, RollProbability, and weighted gacha use strict integer comparisons to avoid floating-point drift in probability decisions.
  • Pluggable & Extensible: IRandomEngine and IPitySystem serve as extension points for custom logic.
  • Test coverage included: Ships with EditMode tests covering determinism, state round-trips, distribution behavior, and pity semantics.

Included Modules

  • Core PRNG: PCG32 engine (PCG-XSH-RR) and OSLRandom developer facade.
  • Shuffling: Deterministic Fisher-Yates shuffle (OSLDeckShuffler).
  • Gacha & Pity System: Immutable weighted draw tables (OSLGachaTable) with a pluggable Hard Pity system for reliable drops.
  • Combat Resolver: Integer-first combat probabilities (OSLCombatResolver for dice, criticals, and percentages).

Requirements

  • Minimum Unity Version: Unity 2021.3 LTS or newer
  • Tested Unity Versions: Keep this field updated per release validation
  • Scripting runtime: .NET Standard 2.1
