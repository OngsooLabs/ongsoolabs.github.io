Technical Details

  • Verification Flow: Uses BackendApiClient to POST receipts to your server. Incorporates automated retries (Max Verification Retries, Retry Delay Seconds) for unstable networks.
  • Apple & Google Logic: Handles distinct validation rules for Apple Sandbox/Production modes automatically. Supports Apple's OriginalTransactionId rules for subscription renewals.
  • Database Architecture: The reference backend uses SQLite and Dapper (Micro-ORM) for zero-config testing, fully ready to migrate to MySQL or PostgreSQL.
  • Input Detection Reflection: Uses safe reflection (UnityEngine.Input try/catch logic) to dynamically switch between StandaloneInputModule and InputSystemUIInputModule without hard dependencies.
  • Configuration Asset: Managed via a centralized IapSetupConfig ScriptableObject for managing environments, endpoints, timeouts, and product catalogs.
