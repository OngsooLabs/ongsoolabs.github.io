Description

OSL IAP Client wraps Unity IAP and adds a critical server-side verification step. Instead of blindly trusting client-side purchase success callbacks, this asset ensures receipts are validated by your own backend server against Google Play and the Apple App Store before any in-game rewards are granted.

Highlights

  • Server-Authoritative: Prevents receipt forgery and replay attacks by forcing backend validation.
  • Seamless Integration: Wraps com.unity.purchasing without modifying it. Missing packages are handled gracefully with fallback stubs.
  • Backend Ready: Includes comprehensive documentation and a deployable backend reference for Google and Apple verification, database management, and webhook handling.
  • Demo Scene Included: A full testing environment with login simulation, consumable (Gold), and subscription (VIP) purchase flows.
  • Input System Compatible: Automatically detects and binds either the legacy Input Manager or the new Input System Package.

Workflow

  1. Player initiates a purchase via Unity IAP.
  2. IapManager intercepts the receipt and sends it to your backend.
  3. Backend validates with Apple/Google and responds.
  4. Rewards are granted only upon semantic success.

Requirements

  • Unity 2021.3 LTS or newer
  • Unity IAP (com.unity.purchasing)
