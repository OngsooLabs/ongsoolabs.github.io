Hello Asset Store Review Team,

Thank you for reviewing the OSL IAP Client. This package provides a secure, server-authoritative workflow wrapper around Unity IAP (com.unity.purchasing).

To verify functionality:

  1. Ensure the Unity IAP package (com.unity.purchasing) is installed via the Package Manager.
  2. Open the Demo Scene located in Assets/OSL/IapClient/Samples/DemoScene.unity.
  3. The included IapSetupConfig asset contains a mock Server URL. To test the complete flow without a real backend, you can modify the BackendApiClient.cs script temporarily to mock a successful JSON response, or deploy the provided backend source code from Assets/OSL/IapClient/Server~/ locally.
  4. Press Play and interact with the Consumable and Subscription purchase buttons.

This package complies with Asset Store distribution rules and does not contain unauthorized third-party binaries.

Thank you!
