Changelog

[1.1.0] - Unreleased

Added

  • Pending Receipt Queue: Implemented persistent file-based local queueing (osl_iap_pending_queue.json) for unverified transactions.
  • Exponential Backoff: Added an intelligent background retry mechanism for the pending queue to recover from network interruptions without user intervention.
  • Verification Failed Event: Added OnVerificationFailed event to notify the application when a receipt is permanently rejected by the server.

Fixed

  • Duplicate Reward Prevention: Hardened idempotency rules to block duplicate item grants if the server inconsistently responds with ShouldGrantReward=true but ShouldConfirmPurchase=false.
  • Task Cancellation: Ensured the background queue processor respects component lifecycle using CancellationTokenSource to prevent MissingReferenceException on app exit or scene change.
  • Queue Recovery: Added automatic deletion of corrupted queue files to prevent endless parsing error loops on application start.

[1.0.0] - Initial Release

Added

  • IapManager: Core wrapper for com.unity.purchasing with server-side validation routing.
  • BackendApiClient: Handles POST requests to the verification server with automatic retry logic.
  • IapSetupConfig: ScriptableObject for centralized environment and product catalog configuration.
  • Input System Support: Dynamic input module detection for backward and forward compatibility.
  • Demo Scene: Includes a complete consumable and subscription purchase flow.
  • Documentation: Extensive backend setup guides for Apple and Google verification.
