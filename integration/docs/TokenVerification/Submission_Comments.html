Hello Asset Store Review Team,

Thank you for reviewing OSL Token Verification. This package provides a secure backend API boilerplate (.NET 8) and a Unity client manager to authenticate social tokens.

To verify functionality:

  1. Extract the backend source from Assets/OSL/TokenVerification/Server~/ or the packaged source archive inside that folder.
  2. Open the extracted folder in a terminal and run dotnet run (requires .NET 8 SDK). The server will start locally (usually on http://localhost:5000, depending on the launch profile).
  3. In Unity, open the Demo Scene located in Assets/OSL/TokenVerification/Samples/Scene/DemoScene.unity.
  4. Set the Server Base Url in the TokenVerifyManager component to your local server address (e.g., http://localhost:5000).
  5. Run the scene, paste a valid provider token into the input field, and click the corresponding provider button to test the end-to-end cryptographic verification.

Thank you!
