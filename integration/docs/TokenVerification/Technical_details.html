Technical Details

  • Architecture: The .NET 8 server uses ASP.NET Core Minimal APIs and HttpClientFactory for high throughput. The Unity client uses standard UnityWebRequest wrapped in TokenVerifyManager.
  • Apple JWKS Caching: Cryptographic validation of Apple JWTs utilizes an in-memory cached JWKS (JSON Web Key Set) updated only every 12 hours.
  • Steam & Discord Validation: Uses native Uri.EscapeDataString to safely transmit hex-encoded Steam tickets. Validates Discord OAuth redirect URIs directly against configured server secrets.
  • UI Agnostic: The Unity Demo Scene dynamically uses Reflection to bind to either legacy UI.Text or TextMeshPro if assigned, falling back to an internal OnGUI implementation to keep the package strictly zero-dependency.
