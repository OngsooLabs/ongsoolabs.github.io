Description

OSL Token Verification is a robust backend boilerplate built with ASP.NET Core Minimal APIs. It pairs with a Unity client manager to provide secure, server-side cryptographic validation for identity tokens and session tickets. Do not rely only on client-side login callbacks—verify tokens on your server.

Highlights

  • Ready-to-Deploy Backend: Includes the full .NET C# source code (TokenVerificationServer) that you can run locally in seconds or deploy to Azure, AWS, or any VPS.
  • Multi-Platform Support: Built-in validation controllers for Google, Facebook, Apple, Steam, and Discord.
  • High Performance: Implements Apple JWKS 12-hour in-memory caching to reduce redundant external API requests and improve resilience during provider-side issues.
  • Security Hardened: Steam session tickets are strictly URL-encoded to prevent payload corruption, and Discord redirect parameters are server-validated to reduce CSRF tampering risk.
  • Unity Helper: Comes with TokenVerifyManager for frictionless HTTP POST communication and a lightweight OnGUI Demo Scene.

Requirements

  • Minimum Unity Version: Unity 2021.3 LTS or later
  • Tested Unity Versions: Keep this field updated per release validation
  • Backend runtime: .NET 8 SDK

Backend Support Policy

The included backend currently targets .NET 8 LTS. Future releases should track migration compatibility with the next supported .NET LTS version before .NET 8 reaches end of support.
