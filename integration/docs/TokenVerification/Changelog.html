Changelog All notable changes to this package are documented here. The format is based on Keep a Changelog (https://keepachangelog.com/en/1.1.0/).

[2.0.0] - 2026-08-29

Changed

  • Migrated the backend starter from .NET 8 to .NET 10 and updated Google.Apis.Auth to 1.76.0, Swashbuckle.AspNetCore to 10.2.3, and System.IdentityModel.Tokens.Jwt to 8.22.0.
  • Replaced permissive CORS with an exact, configurable, deny-by-default origin allowlist and limited Swagger UI to Development.
  • Standardized failure responses around stable error codes and correlation IDs while preserving the existing verification endpoint paths and successful response fields.

Added

  • Added per-IP fixed-window rate limiting, request body limits, provider API timeouts, /healthz, and X-Correlation-ID handling.
  • Added a dependency-free Kestrel smoke-test project covering Production and Development defaults, including CORS, Swagger, request-size, rate-limit, timeout, correlation, and credential-redaction behavior.
  • Added server setup and 1.1.2-to-2.0 migration guides to the canonical source archive.

Security

  • Removed raw provider response bodies and exception details from client errors, and constrained server and Unity client logs to provider, error code, status, and correlation metadata without credentials or identities.
  • Replaced manual Unity request JSON interpolation with JsonUtility serialization so credential characters cannot break request payload structure.

Fixed

  • Normalized TokenVerifyManager.cs to consistent CRLF line endings without changing its logical content, addressing the file condition reported by the Asset Store Validator. A fresh Validator run is still required to confirm that the warning is cleared.

[1.1.2] - 2026-08-23

Changed Repositioned the package as a Unity client and .NET 8 backend verification starter. Distinguished Google/Apple token validation from Facebook/Steam/Discord provider API checks and removed unverified production-deployment claims.

Fixed Included the tracked .NET backend source archive at the TokenVerification package root during .unitypackage export.

[1.1.1] - 2026-08-22

Changed Updated the Token Verification sample input and result presentation so tokens and identity values are not displayed by the sample surface or sample logging.

[1.1.0] - 2026-07-28

Changed

  • Refactored error responses to uniformly return a consistent JSON format with lowercase properties (success, message) to ensure compatibility with Unity's JsonUtility.

Added

  • Added Visual Studio Publish Profile (FolderProfile.pubxml) to support single-file, self-contained executable deployment for Windows and Linux servers.

[1.0.2] - 2026-06-22

Added Discord Token Verification: Added server-side endpoint and cryptographic validation support for Discord authentication codes. Apple JWKS Caching: Implemented a 12-hour in-memory cache for Apple's JSON Web Key Sets (JWKS) to avoid frequent external API calls. Steam Ticket Transmission Safety: Escaped special characters in Steam session tickets via Uri.EscapeDataString to prevent payload corruption during HTTP transmission. Discord Redirect Validation: Validates the OAuth redirection parameters against the server settings to prevent redirect manipulation. Automated Source Packaging: Integrated editor script hook (OSLAssetExporter) to automatically zip the .NET backend project (TokenVerificationServer) into Server_Dotnet_Source.zip upon package export.

Changed Updated package description to reflect official support for Discord token verification. Standardized namespaces and client-side HTTP request payloads to ensure clean integration.

[1.0.1] - 2026-05-27

Changed Bumped com.unity.ugui package dependency version from 1.0.0 to 2.0.0. Cleaned up verification documentation files.

[1.0.0] - 2026-05-12

Added Initial release of the OSL Token Verification System. Standalone .NET Web API boilerplate (TokenVerificationServer) featuring ready-to-use validation controllers for Google, Facebook, Apple, and Steam. Client-side validation helper class TokenVerifyManager for easy HTTP integration inside Unity.
