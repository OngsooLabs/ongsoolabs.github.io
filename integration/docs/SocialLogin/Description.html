Description

OSL Social Login provides a unified interface for integrating various social login platforms into your Unity project. It abstracts specific SDK implementations behind a common C# interface, making it easy to selectively enable, disable, and manage platform-specific code without breaking your build or modifying your game logic.

Highlights

  • Unified Interface: Perform login operations across Apple, Facebook, Google, Steam, and Discord using identical method signatures and callbacks (ISocialLoginProvider).
  • Centralized Setup: Manage all API keys, client tokens, and application IDs in a single Editor window.
  • Soft Dependencies Architecture: Uses conditional define symbols (e.g., OSL_GOOGLE, OSL_DISCORD). Unused SDKs are safely excluded from compiling and won't bloat your build.
  • Automated Build Process: Pre-built processors automatically inject required elements like AndroidManifest values and iOS Info.plist URL schemes dynamically during build time.

Supported Platforms

  • Apple: iOS
  • Facebook: iOS, Android, WebGL
  • Google: iOS, Android, WebGL, Standalone PC
  • Steam: Standalone PC
  • Discord: Standalone PC (Zero-SDK Loopback)
