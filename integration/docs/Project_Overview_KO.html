프로젝트 개요

프로젝트 설명

OSL Integration은 네트워킹, 보안, 소셜 로그인 등을 위한 견고하고 프로덕션 수준의 모듈을 제공하는 유니티 에셋 스토어 패키지 모음입니다.

목표

가능한 한 무거운 서드파티 SDK에 의존하지 않고, 가볍고 서버 권한(Server-authoritative)을 가진 모듈식 솔루션을 개발자에게 제공하는 것입니다.

방향 (아키텍처)

이 프로젝트는 고객의 프로젝트에 불필요한 코드가 들어가지 않도록 계층형 Core 아키텍처를 따릅니다. 상위 모듈은 하위 모듈만 참조할 수 있습니다(단방향 의존성).

  • Layer 0: OSL.Core (Shared Utility): 모든 에셋이 사용하는 초경량 공용 모음집 (예: OSLCrypto, OSLLogger).
  • Layer 1: OSL.Auth.Base (Domain Core): 소셜 로그인 모듈들을 묶어주는 인증 베이스 (ISignin, 토큰 검증).
  • Layer 2: OSL.Product (End Product): 단일 목적을 수행하는 배포 단위 (예: OSL.EasyPatcher, OSL.SecureSave). Layer 0이나 Layer 1만 선별적으로 참조.

진행도

현재 모든 레거시 패키지를 새로운 OSL 표준으로 마이그레이션하고 에셋 스토어 등록용 문서를 생성 중입니다.

구현할 것들

  • 에디터 스크립트를 통한 .unitypackage 추출(Export) 프로세스 자동화.

패키지 세부 사항 (개별 모듈)

OSL Integration 제품군에 포함된 각 패키지들의 세부 설명과 나아갈 방향은 다음과 같습니다.

1. Deterministic

  • 설명: 외부 의존성이나 런타임 메모리 할당(Allocation)이 없는 순수 결정론적 난수 생성(RNG) 스위트.
  • 방향: 디바이스 간 소수점 오차(Drift) 없는 수학적 일관성을 제공하여 Lockstep 멀티플레이어, 롤백(Rollback) 넷코드, 그리고 절차적 생성을 안정적으로 구축하는 기반을 마련합니다.

2. EasyPatcher

  • 설명: 매우 가볍고 직관적인 런타임 패치 다운로드 및 배포 시스템.
  • 방향: 어드레서블(Addressables)과 같은 무거운 시스템 없이도 변경된 파일만 클라우드에서 안전하게(AES/HMAC) 다운로드할 수 있도록 하여 소규모/인디 게임의 패치 편의성을 극대화합니다.

3. IapClient

  • 설명: 클라이언트의 영수증 조작을 방지하는 서버 권한(Server-authoritative) 인앱 결제 검증 래퍼.
  • 방향: Unity IAP에서 결제 성공 시 클라이언트를 맹신하지 않고, 보상을 지급하기 전 반드시 백엔드 서버를 거쳐 Apple/Google 영수증의 진위를 확인하도록 강제합니다.

4. SecureSave

  • 설명: Unity Gaming Services(UGS) 기반의 노코드(No-code) 안티 치트 클라우드 세이브 패키지.
  • 방향: 클라이언트 단의 세이브 파일 조작을 원천 차단합니다. UGS Cloud Code를 거쳐 값의 타입, 최대 증감량(Delta), 범위 등을 서버가 엄격히 검증한 후 저장하도록 유도합니다.

5. SocialLogin

  • 설명: Apple, Facebook, Google, Steam, Discord 로그인을 묶은 통합 소셜 로그인 솔루션.
  • 방향: ISignin이라는 단일 인터페이스로 파편화된 SDK를 추상화합니다. Soft Dependency(어셈블리 조건부 컴파일) 구조를 채택하여, 사용하지 않는 플랫폼의 코드가 프로젝트 빌드를 오염시키지 않도록 보호합니다.

6. SocialLoginPro

  • 설명: SocialLogin 모듈과 TokenVerification 모듈을 하나로 묶은 통합 엔드투엔드 보안 로그인 번들.
  • 방향: 클라이언트에서 획득한 소셜 로그인 토큰을 자체 백엔드 서버에서 암호학적으로 검증하는 과정까지 "턴키(Turn-key)"로 제공하여, 멀티플레이 게임의 인증 인프라 구축 시간을 대폭 단축시킵니다.

7. TokenVerification

  • 설명: 스탠드얼론 .NET 8 웹 API 서버 보일러플레이트와 Unity 클라이언트 통신 매니저 패키지.
  • 방향: 클라이언트 사이드 변조 공격을 막기 위해, 즉시 배포 가능한 ASP.NET 서버 템플릿을 개발자에게 제공함으로써 토큰 유효성 검사를 빠르고 안전하게 수행할 수 있도록 돕습니다.
