Project Overview

💡 Project Description & Identity

OSL Integration is a Modular Backend Infrastructure & Architecture Suite optimized for the Unity Asset Store, providing robust, production-ready modules for networking, security, social login, payment verification, patching, deterministic logic, and server-authoritative workflows. It is designed to reduce data-loss risks and strengthen backend-driven security for commercial Unity projects.

🎯 Goals & Core Values

To provide developers with lightweight, server-authoritative, and modular solutions without relying on bloated third-party SDKs where possible.

  • Zero-Loss-Oriented Reliability: Offline queueing, resumable downloads, and automatic sync patterns to reduce data or payment loss in unstable environments.
  • Server-Authoritative Security: Server-side IAP validation, token verification, and Cloud Code validation to reduce client-side tampering risks.
  • Unity Developer Friendly (DX): Editor diagnostic tooling and one-click server deployment paths tailored for Unity developers without deep backend knowledge.

🏗️ Direction (Architecture)

The project follows a Hierarchical Core Architecture to avoid unnecessary bloat in the customer's project. Upper modules can only reference lower modules (uni-directional dependency).

  • Layer 0: OSL.Core (Shared Utility): An ultra-lightweight common module used by all assets (e.g., OSLCrypto, OSLLogger).
  • Layer 1: OSL.Auth.Base (Domain Core): The authentication base that ties the social login modules together (ISignin, token verification).
  • Layer 2: OSL.Product (End Product): Single-purpose deployment units (e.g., OSL.EasyPatcher, OSL.SecureSave). Selectively references Layer 0 or Layer 1.

Package Details (Individual Modules)

OSL Integration currently contains 7 deliverable packages. The roadmap is organized into 6 major tracks because SocialLoginPro is treated as a bundled end-to-end product that combines SocialLogin and TokenVerification.

1. Deterministic

  • Description: A zero-dependency, allocation-conscious deterministic RNG (Random Number Generator) suite.
  • Direction: Provides a reliable and mathematically consistent foundation for lockstep multiplayer, save-state rollback, and procedural generation across supported and tested platforms.

2. EasyPatcher

  • Description: A lightweight, streaming patch distribution system for Unity.
  • Direction: Aims to replace heavy systems like Addressables for simple patch downloads. It allows developers to push updates via native REST APIs (AWS, GCP, Azure, Unity CCD) and download only changed files at runtime with AES/HMAC-based integrity and payload-protection options.

3. IapClient

  • Description: A server-authoritative In-App Purchase verification wrapper.
  • Direction: Prevents client-side receipt forgery by intercepting Unity IAP callbacks and forcing a secure validation step through the developer's backend server before granting in-game rewards.

4. SecureSave

  • Description: A no-code, server-authoritative save system backed by Unity Gaming Services (UGS).
  • Direction: Reduces client-side save manipulation risks by routing saves through UGS Cloud Code to validate data types, max deltas, and value clamps on the server.

5. SocialLogin

  • Description: A unified Multi-Platform Social Login solution.
  • Direction: Abstracts Apple, Facebook, Google, Steam, and Discord (Zero-SDK) behind a single ISignin interface. Employs soft dependencies (asmdef constraints) to ensure unused SDKs never bloat the project compilation.

6. SocialLoginPro

  • Description: An end-to-end secure sign-in bundle.
  • Direction: Combines SocialLogin with the TokenVerification backend. It provides a turnkey-style pipeline—from client-side OAuth popups to backend cryptographic JWT/ticket verification.

7. TokenVerification

  • Description: A standalone .NET 8 Web API server boilerplate and Unity client.
  • Direction: Provides developers with a ready-to-deploy backend server (ASP.NET Minimal API) to cryptographically verify OAuth identity tokens and reduce client-side spoofing risks.
