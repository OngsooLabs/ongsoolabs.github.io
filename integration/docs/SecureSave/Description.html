Description

OSL Secure Save reduces client-side cheating risks by routing save write operations through a Unity Cloud Code endpoint. Instead of trusting the client to write directly to Cloud Save, this asset enforces server-authoritative validation rules for every configured key.

Highlights

  • Anti-Cheat Validation: Enforces data type matching, min/max range clamping, and maximum delta validation (e.g., gold cannot increase by more than 500 at once).
  • Operation Locking: Lock specific keys to AddOnly, Replace, or Both to reduce malicious overwrites of cumulative stats.
  • Remote Config Integration: Validation rules can be updated live via Unity Remote Config without needing to redeploy client builds or Cloud Code scripts. Hardcoded fallback included.
  • No-Code Backend Path: Deploy the included osl_master_save.js to your UGS Cloud Code dashboard and configure your rules without hosting a custom backend server.

Requirements

  • Minimum Unity Version: Unity 2022.3 LTS or later
  • Tested Unity Versions: Keep this field updated per release validation
  • UGS Core, Authentication, Cloud Save, Cloud Code
  • UGS Remote Config (Optional but recommended)
