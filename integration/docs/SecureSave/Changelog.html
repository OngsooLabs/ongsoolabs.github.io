Changelog

[1.1.2] - 2026-08-23

Changed Repositioned the package as a UGS Cloud Code write-validation workflow and documented type, range, delta, and operation rules. Corrected the minimum Unity version to the package manifest value and clarified the Default access-class and direct-write boundary.

[1.1.1] - 2026-08-22

Changed Updated the Basic Usage sample presentation to omit player identity, service credentials, raw service responses, and queue-file contents from visible output.

[1.1.0] - 2026-07-18 Fixed: StackOverflowException caused by circular dependency between OSLSaveManager and OSLSaveSyncWorker. Fixed: Infinite retry loop caused by Unity Cloud Code SDK's "Array cannot be null" parsing bug on 400 Bad Request responses. Fixed: Queue sync data loss risk when disk write fails. Changed: OSLSaveSyncWorker properly unwraps AggregateException for clearer logging. Changed: Improved IsValidationError to avoid false positives on transient auth errors. [1.0.1] - 2026-06-15 Fixed: Resolved an issue where untyped values were coerced by Cloud Code before validation. Changed: Updated package.json tags and metadata for UPM compatibility.

[1.0.0] - Initial Release Added: OSLSaveManager wrapper for secure UGS writes. Added: JavaScript Cloud Code validation script (osl_master_save.js) supporting Remote Config. Added: Validation rules for Type, Range, Delta, and Operation locking. Added: Basic Usage demo scene.
