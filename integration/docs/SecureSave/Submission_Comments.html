Hello Asset Store Review Team,

Thank you for reviewing OSL Secure Save. This package provides a server-authoritative save data validation framework utilizing Unity Gaming Services (UGS).

To test the package functionality:

  1. Link your Unity project to a valid UGS project with Authentication, Cloud Code, and Cloud Save enabled.
  2. Deploy the included script Assets/OSL/SecureSave/CloudCode/osl_master_save.js to your Cloud Code dashboard. Make sure to define key and operation as String parameters in the UGS dashboard (Do NOT define value as a parameter type in UGS, as it must remain untyped for the script logic to work).
  3. Open the Demo Scene located in Assets/OSL/SecureSave/Samples~/BasicUsage.
  4. Press Play and interact with the UI to see how values violating the rules (e.g., adding too much gold) are rejected by the server.

There are no third-party SDK dependencies outside of the official com.unity.services.* packages.

Thank you!
