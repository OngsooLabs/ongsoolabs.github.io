Technical Details

  • Architecture: Client writes are routed via CloudCodeService.CallEndpointAsync("osl_master_save"). Reads bypass Cloud Code and fetch directly via CloudSaveService for maximum performance.
  • Data Validation Engine: The JavaScript Cloud Code endpoint validates: Type constraints, MinValue/MaxValue clamping, MaxDelta limits for AddOnly fields, and allowed operations.
  • Rule Loading: Rules are parsed from JSON. The script attempts to load osl_secure_save_rules from Remote Config first. If unavailable, it falls back to a locally embedded JSON object.
  • API Wrapper: Provides an easy-to-use OSLSaveManager with strongly-typed methods: AddInt, SetInt, SetString, SetBool, and GetAsync<T>.
