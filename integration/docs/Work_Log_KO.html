작업 내역

[2026-07-09]

  • 프로젝트 폴더 구조 규칙 위반 사항 수정
  • TokenVerification 및 IapClient 패키지의 백엔드 소스 zip 파일을 Server~/ 폴더로 격리
  • SocialLogin, Deterministic 패키지의 문서 폴더 명칭을 Documentation으로 정규화
  • SocialLoginPro, EasyPatcher 패키지의 루트에 방치된 README 파일들을 Documentation/ 폴더 생성 후 이동
  • Project_Rules 문서에 Server~/ 및 글로벌 Editor/ 예외 폴더 규칙 추가
  • 6개 로드맵 트랙으로 구성된 7개 배포 패키지(Deterministic, EasyPatcher, IapClient, SecureSave, SocialLogin, SocialLoginPro, TokenVerification)에 대한 로드맵 기획 완료
  • OSL Integration 스위트의 정체성 명문화 및 에셋 스토어 환경 최적화 강점 서술
  • Roadmap_KO.md, Roadmap_EN.md 문서에 전체 통합 로드맵을 3단계 Phase(인프라 안정성, 로직 고도화, UI 확장)로 재구성하여 갱신
  • Project_Overview_KO.md, Project_Overview_EN.md 최상단에 에셋 스토어 전용 모듈형 스위트로서의 목표와 핵심 가치(안정성, 보안, DX) 명시
  • 패키지 수 표현을 6개 로드맵 트랙 / 7개 배포 패키지로 통일하고, SocialLoginPro를 SocialLogin과 TokenVerification을 결합한 번들 패키지로 명확화
  • every platform, perfect security, guaranteed zero loss 같은 근거 없는 절대 표현을 피하도록 호환성 및 주장 표현 규칙 추가
  • Asset Store 및 UPM-style 패키지 구조를 위해 Samples/, Samples~/, Server~/ 사용 규칙 명확화
  • 패키지 마케팅 문구와 심사관 제출 문구를 supported and tested platforms, reduces risk, detects tampering 같은 근거 기반 표현으로 완화
  • SocialLoginPro 및 TokenVerification 심사관 안내의 메뉴명과 Server~/ 백엔드 소스 경로를 표준화
  • Roadmap_KO.md, Roadmap_EN.md에 로드맵 운용 원칙, Current Focus, Phase별 완료 기준을 추가하여 에이전트가 바로 실행 가능한 구조로 구체화
  • 각 프로젝트별 역할, 현재 아쉬운 점/리스크, 우선순위별 구현 항목, 완료 기준을 추가
  • SocialLoginPro는 별도 기능 트랙이 아니라 SocialLogin + TokenVerification 조합형 배포 패키지로 관리하도록 로드맵 설명을 정리
  • Deterministic Core는 Burst/Job 최적화보다 상태 직렬화, 재현성 테스트, 샘플 검증을 우선하도록 순서를 조정
  • TokenVerification은 Provider 추가 중심이 아니라 배포 편의성, JWKS 캐싱, 기본 Rate Limiting, 보안 미들웨어, Provider validation hardening 중심으로 재정리
  • SecureSave는 오프라인 저장 표현을 Pending Write Queue 기준으로 명확화하고, 재접속 동기화/충돌/실패 처리 기준을 추가
  • EasyPatcher는 Binary Diffing을 즉시 핵심 기능으로 두지 않고, 이어받기/검증/재시도 안정화 후 실험 또는 Feature Flag 기반으로 접근하도록 정리
  • IapClient는 Pending Receipt Queue와 transaction idempotency를 1순위 핵심 완료 기준으로 명확화
  • IapClient 미처리 결제건(Pending Receipt) 영구 파일 로컬 큐잉 및 지수 백오프 기반 백그라운드 재시도 로직 구현
  • IapClient 보상 중복 지급 방지(Idempotency) 로직 보완 및 앱 강제 종료 시 CancellationToken 기반 Task.Delay 안전 종료 처리
