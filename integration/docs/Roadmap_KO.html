OSL Integration 로드맵

💡 OSL Integration의 정체성 및 개발 방향

OSL Integration은 유니티 에셋 스토어(Unity Asset Store) 환경에 최적화된 **"모듈형 백엔드 인프라 및 아키텍처 스위트"**입니다. 각 패키지는 프로젝트에 필요한 것만 골라 쓸 수 있도록 완벽히 독립적(Decoupled)으로 동작하면서도, 통합해서 사용했을 때 강력한 시너지를 냅니다.

  • 안정성 최우선 (Zero-Loss Reliability): 오프라인 큐잉, 이어받기 등 예외 상황에서의 데이터/결제 유실 원천 차단
  • 강력한 보안 (Server-Authoritative): 결제 영수증 검증, 클라우드 코드 기반의 세이브 조작 방지 등 클라이언트 변조 방어
  • 유니티 에셋 친화적 (DX): 서버 지식이 없어도 쉽게 쓸 수 있는 에디터 진단 툴링, 원클릭 서버 배포 등 유니티 개발자 맞춤형 진입 장벽 최소화

🗺️ 통합 로드맵

Phase 1: 인프라 안정성 및 필수 사용성 확보 (Core Reliability & DX)

  1. IapClient & Secure Save - 오프라인 트랜잭션 큐잉 및 자동 동기화 (결제/데이터 유실 방어)
  2. EasyPatcher - 핵심 통신 아키텍처 개선 (HTTP 이어받기, 병렬 다중 다운로드)
  3. SocialLogin - 에디터 환경 진단 툴링 및 자동 로그인(Auto-Login) 매니저
  4. Token Verification - 유니티 친화적 원클릭 배포(Self-Contained) 및 JWKS 캐싱
  5. Deterministic Core - C# Job System & Burst Compiler 네이티브 지원 강화

Phase 2: 비즈니스 로직 고도화 및 최적화 (Advanced Logic & Optimization)

  1. EasyPatcher - 델타 패치(Binary Diffing) 및 메니페스트 압축 지원
  2. IapClient - 구독 상태(VIP 등) 로컬 캐싱 및 클라이언트 1차 영수증 검증
  3. Secure Save - Cloud Code 기반 정규표현식(Regex) 및 화이트리스트 검증 룰셋 추가
  4. SocialLogin - 에디터 전용 Mock(가짜) 로그인 프로바이더 (테스트 편의성)
  5. Token Verification - Discord 소셜 로그인 토큰 검증 API 추가 및 API Rate Limiting
  6. Deterministic Core - 수학적 확장 (Soft Pity 등 신규 로직 및 대체 난수 알고리즘)

Phase 3: 장기 보류 (UI 및 외부 연동 확장)

  • 플랫폼 확장: 원스토어(IapClient), Xbox/PSN(SocialLogin), 커스텀 백엔드 등 신규 연동
  • UI/프론트엔드: Drop-in 소셜 로그인/상점 UI 프리팹, Admin 대시보드 웹앱 등

1. Deterministic Core

1순위: 핵심 아키텍처 및 사용성 개선

  • [ ] Burst Compiler 및 C# Job System 네이티브 지원 강화
  • [ ] 상태 직렬화(Serialization) 편의 기능 추가

2순위: 수학적 확장 (단기 추가 기능)

  • [ ] Soft Pity (점진적 천장) 로직 추가
  • [ ] Xoshiro256, SplitMix64 등 대체 난수 알고리즘 모듈 추가

3순위: 장기 보류 항목 (시각적 데모 씬 필요)

  • [ ] 결정론적 2D/3D 노이즈 (Noise)
  • [ ] 고정 소수점 수학 (Fixed-Point Math)

2. Token Verification

1순위: 백엔드 성능 최적화 및 배포 편의성

  • [ ] 공개키(JWKS) 인메모리 캐싱 적용 (토큰 검증 속도 최적화)
  • [ ] 유니티 친화적 배포: SDK 없는 독립 실행형(Self-Contained) .exe 및 Visual Studio 원클릭 게시(Publish) 프로필 지원

2순위: 단기 추가 기능 (서버 로직 확장)

  • [ ] Discord 소셜 로그인 토큰 검증 API 추가
  • [ ] IP 기반 Rate Limiting (스로틀링) 미들웨어 적용

3순위: 장기 보류 항목 (웹 프론트엔드 및 자체 인증 서버)

  • [ ] 토큰 검증 로그를 위한 Admin Dashboard 웹앱 구축
  • [ ] 자체 JWT 발급(IdP) 및 세션 관리 시스템

3. Secure Save

1순위: 핵심 아키텍처 및 통신 최적화

  • [ ] 오프라인 트랜잭션 큐(Queue) 및 자동 동기화 지원
  • [ ] 선택적 키(Multi-key) 로드 기능 추가 (트래픽 최적화)

2순위: 단기 추가 기능 (클라우드 스크립트 기반)

  • [ ] 정규표현식(Regex) 및 화이트리스트 검증 룰 추가
  • [ ] Cloud Code 로컬 단위 테스트 유틸리티 지원

3순위: 장기 보류 항목 (시각적 UI 및 외부 연동 필요)

  • [ ] 인게임 GM(운영자)용 세이브 에디터 UI
  • [ ] UGS 외 커스텀 백엔드 연동 모듈

4. EasyPatcher

1순위: 핵심 아키텍처 및 통신 개선

  • [ ] HTTP 이어받기(Resumable Download) 지원
  • [ ] 다중 스레드(병렬) 다운로드 지원 (Concurrent Downloads)
  • [ ] 기존 AWS S3 백엔드에 Custom Endpoint URL 입력 옵션 추가 (다양한 S3 호환 클라우드 스토리지 동시 지원)

2순위: 단기 추가 기능 (순수 로직 기반)

  • [ ] 델타 패치 (Delta Patching / Binary Diffing) 기반 대용량 파일 최적화
  • [ ] 메니페스트(version.json) GZip/Brotli 압축 지원

3순위: 장기 보류 항목 (시각적 UI 및 외부 연동 필요)

  • [ ] 인게임 패치 노트 UI 컴포넌트 연동
  • [ ] 네이티브 모바일 OS 백그라운드 다운로드 연동

5. IapClient

1순위: 핵심 아키텍처 및 결제 안정성 강화

  • [ ] 미처리 결제건(Pending Receipt) 로컬 큐잉 및 자동 재시도
  • [ ] 지수 백오프(Exponential Backoff) 기반 네트워크 재시도 로직

2순위: 단기 추가 기능 (순수 로직 기반)

  • [ ] 구독 상태(Subscription Status) 로컬 캐싱 및 TTL 적용
  • [ ] 클라이언트 1차 로컬 영수증 검증 (Local Validation) 옵션 추가

3순위: 장기 보류 항목 (시각적 UI 및 외부 연동 필요)

  • [ ] 인게임 상점(Storefront) 스크롤링 UI 템플릿
  • [ ] 서드파티 앱스토어(원스토어 등) 검증 API 연동

6. SocialLogin & SocialLoginPro

1순위: 핵심 사용성 개선 및 에디터 툴링

3순위: 장기 보류 항목 (시각적 UI 및 콘솔 연동)

  • [ ] 애니메이션이 적용된 'Drop-in' 소셜 로그인 UI 프리팹 템플릿
  • [ ] 콘솔 전용 플랫폼(Xbox Live, PSN, Epic Games) 추가 연동
