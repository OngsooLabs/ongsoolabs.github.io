Changelog

[1.2.0] - 2026-06-22

  • Added: Unified Social Login Pro Bundle (Combined SocialLogin and TokenVerification).
  • Added: Client-Side Pre-Validation for token payloads.
  • Added: Apple JWKS In-Memory Caching (12-hour TTL).
  • Added: Steam Ticket Transmission URL-encoding safety.
  • Added: Discord Redirect server-side validation.
  • Changed: Standardized namespaces and internal API signatures.

[1.1.0] - 2026-06-16

  • Added: Discord Sign-In Support (Zero-SDK) via HTTP loopback with port fallback.

[1.0.1] - 2025-06-10

  • Added: UPM compatibility.
  • Fixed: Google standalone PC loopback handling.

[1.0.0] - Initial Release

  • Added: Platform authentication adapters and central SocialLoginSetup UI.
