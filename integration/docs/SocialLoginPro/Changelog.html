Changelog All notable changes to this package are documented here. The format is based on Keep a Changelog (https://keepachangelog.com/en/1.1.0/).

[1.3.0] - 2026-08-28

Changed

  • Included SocialLogin 1.2.0: typed credentials as an optional advanced contract, Google Windows PKCE S256 and state validation, Unity client secret removal, default timeout/cancellation, callback cleanup, duplicate request protection, and actionable setup validation. The basic LoginAsync(ProviderKind) and SocialLoginResult.Token handoff remain compatible.

[1.2.2] - 2026-08-23

Changed Reworked product and customer documentation around the client sign-in to backend verification workflow. Clarified provider-specific verification, platform limits, and the boundary between the included starter and a production deployment.

Fixed Included the tracked TokenVerification backend source archive in the composite .unitypackage export.

[1.2.1] - 2026-08-22

Changed Updated included sample presentation and sample callback logging to omit token and identity values from visible output. Corrected the visible Social Login Setup window title and provider guidance labels.

[1.2.0] - 2026-06-22

Added Unified Social Login Pro Bundle: Combined SocialLogin and TokenVerification into a single, cohesive Unity package. Client-Side Pre-Validation: Integrated quick input sanitization and payload validation before sending requests to the token verification server. Apple JWKS In-Memory Caching: Implemented a 12-hour in-memory cache for Apple's JSON Web Key Sets (JWKS) to optimize token verification performance and improve resilience during external network hiccups. Steam Ticket Transmission Safety: Added robust URL encoding validation for Steam session tickets to prevent special-character transmission issues during verification requests. Discord Redirect Validation: Enabled server-side verification of Discord redirection parameters to protect against redirect tampering vulnerabilities.

Changed Standardized namespaces and internal API signatures to ensure seamless out-of-the-box compatibility between SocialLogin and TokenVerification. Updated package manifest to v1.2.0 and updated comprehensive setup documentation.

[1.1.0] - 2026-06-16

Added Discord Sign-In Support (Zero-SDK): Integrated a pure HTTP loopback auth provider with port fallback support (probing ports 50000-50009), cryptographic CSRF protection, and automatic timeout handling. Centralized editor configuration in SocialLoginSetup.cs for enabling Discord Sign-In (OSL_DISCORD define symbol) and setting credentials.

Changed Fast Enter Play Mode Support: Removed static instance backing fields in SocialLoginSettings to comply with Unity Project Auditor rules. Documentation updated with comprehensive Discord integration and loopback redirect setup guidelines.

[1.0.1] - 2025-06-10

Added UPM compatibility configuration (package.json). Packaging guide for UPM installation.

Fixed Google standalone PC local loopback handling to properly process redirect callback under high-latency network conditions.

[1.0.0] - 2025-01-01

Added Initial release. Unified social login contract interfaces (ISocialLoginProvider and ISignin). Platform authentication adapters: Google (GProvider), Facebook (FBProvider), Apple (AProvider), and Steam (StProvider). Centralized configuration UI via the SocialLoginSetup editor window. Soft-dependency compilation architecture with assembly definitions using conditional define constraints.
