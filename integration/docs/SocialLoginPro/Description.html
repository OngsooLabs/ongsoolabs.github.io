Description

OSL Social Login Pro is a unified, production-ready security package that seamlessly integrates client-side social authentication (SocialLogin) with a robust backend token verification server boilerplate (TokenVerification).

By bridging client-side credential retrieval with backend cryptographic signature and ticket verification, this suite provides an end-to-end secure sign-in pipeline for Unity-based multiplayer games and applications. Never trust client-side tokens—verify them securely with your own backend!

Highlights

  • All-in-One Solution: Combines client SDK management (Apple, Google, Facebook, Steam, Discord) with an included .NET Web API server template for instant backend deployment.
  • Zero-SDK Discord & Steam Auth: Supports standalone PC loopback flows (HttpListener) for Discord, and native Steam session ticket retrieval without bloated third-party plugins.
  • Client-Side Pre-Validation: Quickly sanitizes payload inputs before dispatching requests, saving backend bandwidth and preventing malformed requests.
  • Soft Dependencies Architecture: Uses asmdef defines to ensure unused SDKs are completely excluded from compilation.

Included Modules

  • SocialLogin (Client): Manages OAuth browser loops, native SDK integrations, and unified ISocialLoginProvider interfaces.
  • TokenVerification (Client & Server): Features the TokenVerifyManager and a lightweight ASP.NET Minimal API backend boilerplate to validate Google, Apple, Facebook, Steam, and Discord tokens safely.
