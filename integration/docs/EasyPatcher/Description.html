Description

OSL Easy Patcher is a lightweight, streaming patch distribution system for Unity games. Upload your patch files directly from the Unity Editor to the cloud, and let players automatically download only the changed files at runtime — no Addressables, no complex setups, and no third-party SDKs required.

Highlights

  • Automated Differential Downloads: Automatically compares version.json and downloads only the files that have changed.
  • Multiple Cloud Backends: Upload directly to Google Cloud Storage (GCS), AWS S3, Unity Cloud Content Delivery (CCD), Azure Blob Storage, or a Local Folder right from the Editor.
  • Robust Security: Secure your patch payload with AES-256 (CBC+PKCS7) encryption and HMAC tamper-proofing toggles on a per-file or folder basis.
  • Zero Third-Party SDKs: Communicates with AWS, GCS, and Azure purely through their native REST APIs. No bloated SDKs to bloat your build.
  • UI Agnostic: Comes with OSLPatchUIController which auto-detects TextMeshPro (OSL_TMP_PRESENT) with automatic legacy UI.Text fallback.

Requirements

  • Unity 2021.3 LTS or later (tested up to Unity 6)
  • Scripting runtime: .NET Standard 2.1
