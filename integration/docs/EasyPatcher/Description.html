Description

OSL Easy Patcher is a lightweight, streaming patch distribution system for Unity games. Upload your patch files directly from the Unity Editor to the cloud, and let players automatically download only the changed files at runtime — no Addressables, no complex setups, and no bundled cloud SDKs required.

Highlights

  • Automated Differential Downloads: Automatically compares version.json and downloads only the files that have changed.
  • Multiple Cloud Backends: Upload directly to Google Cloud Storage (GCS), AWS S3, Unity Cloud Content Delivery (CCD), Azure Blob Storage, or a Local Folder right from the Editor.
  • Integrity & Payload Protection: Optional AES-256 (CBC+PKCS7) encryption and HMAC verification help detect corrupted or modified patch files and protect payload contents.
  • No Bundled Cloud SDKs: Communicates with AWS, GCS, and Azure through native REST APIs instead of bundling heavy cloud SDKs into the Unity package.
  • UI Agnostic: Comes with OSLPatchUIController which auto-detects TextMeshPro (OSL_TMP_PRESENT) with automatic legacy UI.Text fallback.

Requirements

  • Minimum Unity Version: Unity 2021.3 LTS or later
  • Tested Unity Versions: Keep this field updated per release validation
  • Scripting runtime: .NET Standard 2.1
