Technical Details

  • Architecture: Employs a Strategy-pattern runtime loader (IOSLLoader) combined with OSLPatchManager for robust, streaming, hash-verified downloading.
  • Integrity & Protection: AES-256 CBC encryption and HMAC-SHA256 verification help protect patch payloads and detect corrupted or unauthorizedly modified downloaded files. HMAC verification is performed on the client against manifest-declared hashes.
  • Backend Integrations: The Editor Uploader utilizes pure REST APIs (including Shared Key authentication for Azure, AWS Signature V4 for S3) to deploy files directly to cloud buckets without importing native cloud SDKs.
  • Versioning: Utilizes version.json file-level manifest tracking (SHA256, Size, Encryption flags).
  • Editor Tooling: Provides an intuitive hierarchical tree view in the Uploader Window to selectively encrypt or exclude files/folders.
  • Test Coverage: Includes a PatchTestRunner that covers 5 end-to-end scenarios (including forced corruption and hash mismatch recovery).
