[1.4.0] - Unreleased (Release pending)

Release status

  • EP-13A and EP-14A implementation, documentation, Unity EditMode validation, and package-isolation validation are complete for this candidate.
  • .unitypackage export and the date-confirmed repository release gate remain pending. No Asset Store submission, review, approval, or public release is claimed.

Added

  • EP-13A runtime download hardening: manifest path safety, verified .part promotion, safe Range fallback, cancellation/stall handling, streaming SHA-256/HMAC verification, and atomic local-manifest updates.
  • An additive StartDownloadAsync(CancellationToken) overload while preserving the existing StartDownloadAsync() call.
  • Optional GZip and Brotli version.json sidecars with explicit runtime preference and uncompressed fallback.
  • An optional path-style S3-compatible upload endpoint while preserving the existing AWS S3 virtual-host endpoint by default.
  • Editor tests for manifest compression, sidecar generation, legacy settings compatibility, endpoint encoding, and invalid endpoint rejection.
  • An 8 MiB limit for remote and decompressed manifest data before JSON parsing.

Compatibility

  • Plain version.json, local_version.json, patch payload URLs, and the existing two-argument OSLPatchManager constructor remain unchanged.
  • EP-13A validation passed in Unity 6000.3.12f1 EasyPatcher EditMode (87/87, failed/skipped 0), including traversal, Range response, validator, cancellation/stall, SHA/HMAC-mismatch non-exposure of final/.part/.meta, and atomic I/O-failure cases.

[1.2.2] - 2026-08-23

Changed Reworked Asset Store, package, public article, and customer guide messaging around changed-file downloads, HTTP Range resume behavior, per-file retries, and cloud-SDK-free upload integrations. Added exact import-and-compile-tested Unity versions and clarified resume and client-side protection limits.

[1.2.1] - 2026-08-22

Changed Updated the package sample presentation to omit endpoint URLs, credentials, local paths, and raw transport errors from visible status output.

[1.2.0] - 2026-07-12

Added OSLPatchManager: HTTP Range requests support for resumable downloads. Interrupted downloads now resume from where they left off. OSLPatchManager: Independent file retry logic. If a file fails hash verification, only the corrupted file is deleted and re-downloaded, rather than aborting the entire patch process. StartServer.ps1: Test server script updated to support HTTP 206 Partial Content (Range requests) and artificial throttling for testing resumable downloads locally.

Fixed OSLUploaderWindow: Fixed Serialization depth limit 10 exceeded Unity error caused by recursive JsonUtility serialization on deep folder structures by flattening the tree node list for storage. OSLLocalUploader: Resolved DirectoryNotFoundException when changing source folder paths without refreshing the internal tree state.

Changed package.json version bumped to 1.2.0.

[1.1.0] - 2026-06-14

Added Azure Blob Storage backend (OSLAzureUploader): upload patch files to any Azure Storage Account container via the Storage REST API with Shared Key authentication — no Azure SDK required. Editor fields: Account Name, Account Key, Container Name, Blob Prefix. Automatic content-type mapping for common Unity asset file extensions. Azure Blob Storage setup guide added to README.md under Upload Backends — Detailed Setup (4-step walkthrough: create storage account → copy access key → configure editor → set runtime URL). "azure" keyword added to package.json. Runtime UI fallback warning: OSLPatchUIController.Start() now emits Debug.LogWarning when both OSL_UGUI_PRESENT and OSL_TMP_PRESENT scripting symbols are absent, so developers are notified that all UI bindings are compiled out.

Fixed Editor security hint text corrected from "32 hex bytes" to "32 bytes = 64 hex characters" in the Encryption / HMAC key warning panel, preventing confusion when setting OSL_PATCH_AES_KEY and OSL_PATCH_HMAC_KEY environment variables.

Changed package.json description updated to include Azure Blob Storage in the supported backend list. package.json version bumped to 1.1.0.

[1.0.1] Fixed OSLPatchManager: HMAC verification now runs whenever the manifest declares an hmacHash, regardless of the encrypted flag. Missing keys are reported as a hard failure instead of silently passing. OSLPatchManager: unified local cache path with the loader (persistentDataPath/OSL/EasyPatcher); per-file download timeout removed for large files; progress is clamped to [0,1]. OSLPatchUIController: Start() is wrapped in try/catch so a failed patch flow no longer leaves the UI in an undefined state. OSLUploaderWindow / OSLSimpleBundleLoader: AES is pinned to CBC + PKCS7 on both encrypt and decrypt paths. PatchTestRunner: hash-mismatch scenario now skips only local_version.json, so corruption is applied to a real payload file. PatchManifest: files list is initialized; PatchFileInfo carries fileName, sizeBytes, sha256Hash, encrypted, and hmacHash consistently across editor and runtime. OSL.EasyPatcher.Runtime.asmdef: corrected TMP versionDefines wiring.

Added package.json for UPM compatibility. README Publishing section describing .unitypackage export and UPM install flows.

[1.0.0] - 2025-01-01 Added Initial release. Strategy-pattern runtime loader (IOSLLoader) and OSLSimpleBundleLoader. Streaming, hash-verified OSLPatchManager with optional HMAC verification. Editor uploader window with Upload / Download / Versions tabs. Hierarchical tree view with per-file/folder encryption and tamper-proof toggles. Versioned patch slots. Upload backends: Local Folder, Google Cloud Storage, AWS S3, Unity CCD. TMP-friendly OSLPatchUIController with automatic legacy UI.Text fallback. Sample PatchTestRunner covering 5 end-to-end scenarios. Assembly definitions for clean Runtime / Editor / Sample separation.
