Changelog

[1.1.0] - 2026-06-14

  • Added: Azure Blob Storage backend (OSLAzureUploader) via REST API with Shared Key auth.
  • Added: Automatic content-type mapping for common Unity asset file extensions.
  • Added: UI fallback warning if both UGUI and TMP are absent.
  • Fixed: Editor security hint text for Encryption / HMAC keys.

[1.0.1]

  • Fixed: HMAC verification now runs whenever the manifest declares an hmacHash. Missing keys cause a hard failure.
  • Fixed: Unified local cache path with the loader (persistentDataPath/OSL/EasyPatcher).
  • Fixed: OSLPatchUIController Start wrapped in try/catch to prevent undefined UI states on failure.
  • Changed: AES is pinned to CBC + PKCS7.

[1.0.0] - 2025-01-01

  • Added: Initial release featuring OSLPatchManager and Uploader Window.
  • Added: Backends for Local Folder, Google Cloud Storage, AWS S3, Unity CCD.
