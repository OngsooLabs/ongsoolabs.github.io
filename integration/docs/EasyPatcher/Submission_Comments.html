Hello Asset Store Review Team,

Thank you for reviewing OSL Easy Patcher. This package provides a standalone file patching solution that operates entirely without third-party SDKs or the Addressables system.

To verify functionality:

  1. Open the Uploader via Tools > OSL > Easy Patcher Uploader.
  2. Generate a local patch by pointing to a dummy folder and selecting the Local Folder backend.
  3. Start a simple local HTTP server (e.g., python -m http.server 8080) pointed to the destination folder.
  4. Attach OSLPatchUIController in an empty scene, point it to http://localhost:8080, and press Play. The system will download and verify the mock patch files.
  5. Alternatively, you can run the included PatchTestRunner script in Assets/OSL/EasyPatcher/Samples which automates end-to-end testing, including simulated file corruption and HMAC verification.

The package strictly relies on UnityWebRequest and standard .NET Standard 2.1 libraries.

If you require access to test our pre-configured AWS/GCP buckets, please reach out to our support email. Thank you!
