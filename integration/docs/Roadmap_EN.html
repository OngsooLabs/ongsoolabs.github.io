OSL Integration Roadmap

💡 Identity & Direction of OSL Integration

OSL Integration is a "Modular Backend Infrastructure & Architecture Suite" fully optimized for the Unity Asset Store. Each package functions entirely independently (decoupled) so developers can pick and choose what they need, yet they provide powerful synergy when used together.

  • Zero-Loss Reliability: Offline queueing, resumable downloads, and automatic sync to prevent any data or payment loss.
  • Server-Authoritative Security: Server-side IAP validation and Cloud Code validation to strictly prevent client-side tampering and cheating.
  • Unity Asset Friendly (DX): Editor diagnostic tooling, one-click server deployments, and simple mock providers tailored for pure Unity developers to use backend systems without server knowledge.

🗺️ Integrated Roadmap

Phase 1: Core Reliability & DX (Foundation)

  1. IapClient & Secure Save - Offline transaction queueing & automatic synchronization (Loss prevention)
  2. EasyPatcher - Core communication improvements (HTTP Resumable & Concurrent downloads)
  3. SocialLogin - Editor Diagnostics tooling & Auto-Login Manager
  4. Token Verification - Unity-friendly One-Click deployment (Self-Contained) & JWKS caching
  5. Deterministic Core - Native support for C# Job System & Burst Compiler

Phase 2: Advanced Logic & Optimization

  1. EasyPatcher - Delta Patching (Binary Diffing) & Manifest compression
  2. IapClient - Subscription status local caching & Client-side local validation
  3. Secure Save - Regex and Whitelist validation rules in Cloud Code
  4. SocialLogin - Mock Social Login Provider for Editor (Testing convenience)
  5. Token Verification - Discord token verification API & IP-based Rate Limiting
  6. Deterministic Core - Mathematical extensions (Soft Pity & Alternative RNGs)

Phase 3: Long-term / On Hold (UI & External Integrations)

  • Platform Expansion: OneStore (IAP), Xbox/PSN (SocialLogin), Custom Backends.
  • UI & Frontend: Drop-in UI templates for Store/Social, Admin Dashboard Web Apps.
